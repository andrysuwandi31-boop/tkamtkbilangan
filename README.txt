RUANG TKA MATEMATIKA KELAS VI
=============================

ISI PAKET
- index.html      Aplikasi web utama
- manifest.json   Metadata aplikasi web
- sw.js           Cache untuk penggunaan offline setelah pertama kali dibuka melalui hosting/server lokal

CARA MENJALANKAN LANGSUNG
1. Ekstrak ZIP ke komputer.
2. Buka folder tka_matematika_web.
3. Klik dua kali index.html atau buka dengan Chrome/Edge/Firefox.
4. Aplikasi langsung berjalan. Tidak memerlukan instalasi, API key, atau koneksi internet.

CARA MEMBAGIKAN KEPADA MURID
- Untuk penggunaan di komputer: bagikan file index.html atau folder/ZIP ini.
- Untuk dibuka melalui tautan website pada HP: unggah isi folder ini ke layanan hosting website statis (misalnya GitHub Pages, Netlify, atau Vercel). Setelah di-host, bagikan URL kepada murid.
- Setelah dibuka pertama kali melalui URL hosting, aplikasi dirancang agar aset utamanya dapat digunakan kembali saat offline pada browser yang mendukung service worker.

FITUR
- Materi belajar mandiri 6 bab.
- 4 contoh soal beserta pembahasan langkah demi langkah.
- 30 soal latihan dari modul sumber.
- Urutan soal dan opsi jawaban diacak pada setiap sesi.
- Pilihan sesi 10, 20, atau 30 soal.
- Navigasi antarsoal dan penanda soal yang sudah dijawab.
- Skor otomatis, umpan balik, serta pembahasan per soal.
- Ulangi khusus soal yang salah.
- Cetak hasil evaluasi.
- Jawaban diproses di browser dan tidak dikirim ke server.

CATATAN
Aplikasi ini merupakan website statis. Belum dipublikasikan ke internet karena penerbitan memerlukan akun/hosting milik pengelola. File dapat langsung dijalankan secara lokal atau diunggah ke hosting statis.
